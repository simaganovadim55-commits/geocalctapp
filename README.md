# GeoCalc — геодезический калькулятор

Telegram Mini App для геодезических расчётов. Статический сайт на GitHub Pages
(HTML + CSS + JS, без сборки и зависимостей), дизайн в стиле iOS.

- **Сайт:** https://simaganovadim55-commits.github.io/geocalctapp/
- **Текущая версия:** 5.0
- **Автор:** prod.by simvol

## Возможности

| Вкладка | Что считает |
|---|---|
| Невязки | СКП по Бесселю и по конспекту (серии), m_m, Δ_пред, проверка свойств случайных ошибок, гистограмма |
| Нивелир | Невязка f_h, допуск по классу (II — 5, III — 10, IV — 20, техн. — 50 мм√L), уравнивание отметок |
| Ходы → Теодолитный ход | Угловая и линейная невязки, 1:T с выбором допуска, координаты с поправками |
| Ходы → Ведомость | Замкнутый и разомкнутый ход, правые и левые углы, висячий ход, поправки Боудича, подробный разбор |
| Задачи | Прямая и обратная задачи, вероятности и таблица Лапласа Φ(x), взвешенные измерения |
| Справка | Выбор темы (Авто / Светлая / Тёмная), формулы, версия |

## Структура

```
index.html   разметка всех экранов, панель вкладок, верхняя панель
style.css    дизайн-токены (светлая и тёмная тема) и компоненты в стиле iOS
app.js       расчёты, тема, навигация, редактор строк, поля ° ′ ″, сохранение ввода
README.md    этот файл
```

### Как устроен `app.js`

- **Расчёты:** `calcAR`, `calcLev`, `calcTh`, `calcVed`, `calcFwd`, `calcInv`, `calcWt`, `phi`.
  Они читают значения из полей (`input`, `textarea`) и рисуют результат через `innerHTML`.
- **Разбор ввода:** `parseNum`, `parseDeg` (формат «ГГ ММ СС» или десятичные градусы),
  `parseLines`, `takeLines`. Нераспознанные строки не пропускаются молча:
  пользователь видит их номера.
- **Виджеты ввода:** редактор строк (`renderRows`, `edWrite`) и поля угла ° ′ ″ (`buildDms`).
  Источником данных для расчётов остаются исходные `textarea` и `input[data-dms]`,
  виджеты только записывают в них значения. Поэтому код расчётов от UI не зависит.
- **Тема:** `themeMode` — `auto`, `light` или `dark`, хранится в `localStorage['geocalc.theme']`.
  Тема задаётся атрибутом `data-theme` на `<html>`. Инлайн-скрипт в `<head>` ставит её
  ещё до отрисовки, чтобы не было вспышки белого фона.
- **Сохранение ввода:** все поля сохраняются в `localStorage['geocalc.inputs.v1']`.

## Выпуск новой версии (важно)

1. Внести изменения и проверить их локально: открыть `index.html` в браузере.
2. **Поднять номер версии в `?v=` у `style.css` и `app.js` в `index.html`.**
   Без этого Telegram возьмёт старые стили из кэша и вёрстка сломается:
   так уже случилось при выпуске 5.0.
3. Обновить номер версии в трёх местах:
   - `<meta name="version">`;
   - плашка `brand-ver` в верхней панели;
   - строка «Версия» в Справке.
4. Слить изменения в `main`. GitHub Pages обновится за 1–3 минуты.
5. В Telegram полностью закрыть и снова открыть мини-приложение.

## Telegram

- Приложение открывается кнопкой меню бота. Настройка в @BotFather:
  **Bot Settings → Menu Button → Configure menu button**, туда вставляется ссылка на сайт.
- Серверной части и токена бота нет, и они не нужны. **Токен никогда не коммитить в репозиторий.**
- Если понадобится отправлять результаты в чат, нужен отдельно работающий бот
  (свой сервер или хостинг). Токен тогда хранится только в переменных окружения.
  Учтите: `tg.sendData` работает, только если приложение открыто кнопкой обычной
  клавиатуры (KeyboardButton), а не кнопкой меню.

## Дизайн

- Цвета — системные цвета iOS. Токены лежат в `:root` и в блоке тёмной темы `style.css`
  (`--bg`, `--card`, `--label`, `--label2`, `--sep`, `--fill`, `--tint`, `--green`, `--red` и др.).
- Шрифт — системный (`-apple-system`). Размеры — по шкале Dynamic Type:
  34 / 17 / 15 / 13.
- Компоненты: сгруппированные списки (`.group`, `.row`), кнопки-капсулы (`.btn`),
  сегментированный переключатель (`.seg-ctrl`), итоговая карточка (`.hero`),
  переключатель iOS (`.switch`), стеклянная панель вкладок (`.bottom-nav`).
- Концепт дизайна (холст с макетами) лежит в артефакте Claude «GeoCalculator iOS концепт».
